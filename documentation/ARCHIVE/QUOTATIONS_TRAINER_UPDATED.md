# Quotations Module Trainer - Updated Implementation

## Overview

Reworked trainer content for the Quotations module based on actual system functionality. Covers enquiry management from racconti.in website, PPTX presentation generation with fixed branding, BOQ quotation creation with XLSX export, and comprehensive analytics.

## Module Workflow

### 1. Enquiries Tab
**Purpose**: Capture and manage customer enquiries from racconti.in website

**Key Features**:
- Enquiries submitted from racconti.in with product lists
- View customer details and selected products
- Team collaboration on enquiries
- Convert to presentations or quotations
- Track enquiry status (New, Quoted, Won, Lost)

**User Actions**:
- View all enquiries in organized list
- Review customer information and requirements
- See products selected with quantities
- Work on enquiries collaboratively
- Convert to presentation (PPTX) or quotation (XLSX)
- Update status as enquiry progresses

### 2. Presentations Tab
**Purpose**: Create branded PowerPoint presentations for clients

**Key Features**:
- Generate PPTX files in fixed branded theme
- Automatic company branding (logo, colors, fonts)
- Product slides with images and descriptions
- Downloadable for client sharing
- Editable in PowerPoint or Keynote for finishing touches

**User Actions**:
- Create presentation from enquiry or manually
- Add products from catalogue
- System applies fixed branded theme automatically
- Generate and download PPTX file
- Further edit in PowerPoint/Keynote if needed
- Share with clients via email

### 3. Quotations Tab
**Purpose**: Generate Bill of Quantities with detailed pricing

**Key Features**:
- BOQ (Bill of Quantities) format
- Multiple products with quantities
- Comprehensive pricing details
- Discounts and tax calculations
- Fixed branded XLSX format
- Modify and re-download capability
- Editable in Excel for final adjustments

**User Actions**:
- Create quotation from enquiry
- Add multiple products with quantities
- Provide all pricing details (unit price, discounts, taxes)
- Generate branded XLSX file
- Download quotation
- Modify and regenerate as needed
- Track version history

### 4. Analytics Tab
**Purpose**: Track performance and conversion metrics

**Key Features**:
- Enquiry conversion tracking
- Quotation performance metrics
- Revenue analytics
- Response time monitoring
- Win/loss analysis
- Team performance tracking

## Key Terminology

### Enquiry
Customer request captured from racconti.in website including:
- Customer contact details
- Selected products with quantities
- Requirements and messages
- Submission date and time

### PPTX Presentation
Visual, branded PowerPoint document:
- Fixed branded theme (logo, colors, fonts)
- Product showcase with images
- Professional layout
- Downloadable and editable
- Used for initial pitches and client meetings

### BOQ Quotation
Bill of Quantities - detailed pricing document:
- Line items with quantities and unit prices
- Discounts and taxes
- Subtotals and grand total
- Fixed branded XLSX format
- Downloadable and editable
- Used for formal pricing proposals

### Fixed Branded Theme
Pre-configured company branding:
- Company logo
- Brand colors
- Font styles
- Layout and design
- Applied automatically to all documents
- Ensures consistency
