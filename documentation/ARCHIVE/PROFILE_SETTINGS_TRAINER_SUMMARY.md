```
1. Navigate to Profile page
2. Click "Edit Profile"
3. Update desired fields
4. Click "Save"
5. Changes sync immediately
6. Verify updates across devices
```

### Changing Photo
```
1. Click on profile photo
2. Select "Upload Photo"
3. Choose image file
4. Wait for upload
```
