# Dashboard Quick Reference Card

## 🎯 Quick Actions

| Action | How To |
|--------|--------|
| **Open Help** | Click `!` button or press `Ctrl+/` |
| **Rearrange Widget** | Click & drag to new position |
| **Resize Widget** | Click resize icon on widget |
| **Change View** | Click view mode button (top-right) |
| **Reset Layout** | Click "Reset Layout" button |
| **Pin Module** | Click "Modules" → Pin icon |

## 📊 View Modes

| Mode | Best For | Info Density |
|------|----------|--------------|
| **Compact** | Many widgets, quick overview | Minimal |
| **Normal** | Balanced view, daily use | Medium |
| **Expanded** | Detailed analysis, deep dive | Maximum |

## 🧭 Navigation

### Top Bar (Left to Right)
1. **Logo** - Return to dashboard
2. **!** - Open trainer/help
3. **☀/🌙** - Toggle theme
4. **⬇** - Install app (when available)
5. **👤** - Profile, settings, logout

### Bottom Bar (Left to Right)
1. **Dashboard** - Main dashboard
2. **Messages** - Conversations (badge = unread)
3. **Search** - Global search
4. **Notifications** - Alerts (badge = unread)
5. **Modules** - Module manager
6. **[Pinned]** - Your custom shortcuts

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+/` or `Cmd+/` | Toggle trainer |
| `ESC` | Close panels |

## 💡 Pro Tips

### Widget Management
- **Drag anywhere** on widget to move it
- **Individual resize** remembers per widget
- **Bulk resize** affects all widgets
- **Auto-save** happens automatically

### Module Shortcuts
- **Pin frequently used** modules
- **Scroll horizontally** if many pinned
- **Badges show** unread counts
- **Syncs across** all devices

### Customization
- **All preferences saved** to your account
- **Works on all devices** where you're logged in
- **Reset anytime** to start fresh
- **No limit** on customization

## 🔄 Real-Time Features

- **Widgets update** automatically
- **Badges update** as items are read
- **No refresh needed** - always current
- **Live data** across all modules

## 📱 Mobile Tips

- **Bottom nav auto-hides** when scrolling down
- **Swipe up** to show bottom nav
- **Widgets stack** vertically
- **Touch-friendly** targets

## ❓ Common Questions

**Q: Why can't I see a module?**
A: Module must be activated by admin

**Q: Can I hide widgets?**
A: Deactivate module to hide widget

**Q: Do changes sync?**
A: Yes, across all your devices

**Q: How to undo changes?**
A: Use "Reset Layout" button

**Q: What do badges mean?**
A: Unread count for that section

**Q: Can I customize colors?**
A: Theme colors set by organization

## 🛠️ Troubleshooting

| Issue | Solution |
|-------|----------|
| Widget won't move | Ensure you're dragging from widget body |
| Layout looks wrong | Click "Reset Layout" |
| Module not showing | Check with admin for activation |
| Badges not updating | Refresh page or check connection |
| Changes not saving | Check internet connection |
